## Summary

Brainstormed (via the `superpowers:brainstorming` skill) and wrote a design
spec for integrating the LingoBites-Server "AI analysis async job" API
(`POST /v1/ai/analyses` + `GET /v1/ai/analyses/:analysis_id`) into the mobile
app, replacing the current synchronous `POST /v1/ai/analyze` call and the
fake, timer-driven progress bar in `AnalyzingScreen` with real, stage-based
progress from polling. No implementation code was written yet — this session
only produced the design document; a follow-up session will use
`writing-plans` to turn it into an implementation plan.

Key decisions captured in the spec (all confirmed with the user via
clarifying questions):
- Async fully replaces sync in the app (no client-side feature flag, no
  fallback path).
- `AnalyzingScreen` is upgraded to render real progress (6 named stages,
  weighted percent, server-provided Vietnamese status messages) instead of
  the current fake 3-step timer simulation.
- Mock mode (`useMockAi=true`) simulates the same staged-progress interface
  so dev/demo UX stays aligned with production and exercises the same
  rendering code path.
- Client-side poll give-up timeout (75s) is treated identically to a
  server-reported `failed` job.
- `src/shared/api/analyzeClient.ts` (the old sync client) and its test are
  planned for deletion once the async path lands, since they become dead
  code.

## User review

- This is a **design document only** — no application code has changed yet.
  Please review the spec's architecture, type shapes, and error-code mapping
  before the implementation plan is written, since those decisions (e.g.
  deleting `analyzeClient.ts`, the 75s give-up timeout, the 1.5s poll
  interval) will drive the next session's plan.
- The spec assumes `ASYNC_ANALYSIS_ENABLED=true` is reliably on in every
  environment the app talks to, since sync is being fully removed rather than
  kept as a fallback. Worth double-checking with backend that this flag is
  set (or will be set) everywhere before implementation starts.
- Source-of-truth doc referenced:
  `LingoBites-Server/docs/01-ba/02-technical/14-ai-analysis-async-job-client-integration-guide.md`.
  If that doc changes before implementation, the spec should be re-checked
